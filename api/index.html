    API Reference¶

    Complete autodoc for the public surface of cmenpy. Every class, function and type alias the framework exposes is documented here, grouped by subpackage. Each symbol links to the page that documents it.

    How to read this reference

    Documentation is generated from the source via mkdocstrings. Signatures are shown with their annotations, and class initializers are merged into the class entry.
