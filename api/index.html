    API Reference¶

    Complete autodoc for the public surface of cmenpy, organized by kind. Every class, function and type alias the framework exposes is documented here, and each symbol links to the page that documents it.

    Browse Contents
    Classes Optimizers, field markers, population, buffer, objectives, search space, runtime, protocols, aliases
    Functions Declaration decorators, kernel decorators, signature markers, builders, introspection, comparators
    Modules One entry per subpackage, with its docstring and links to its symbols

    How to read this reference

    Documentation is generated from the source via mkdocstrings. Signatures are shown with their annotations, and class initializers are merged into the class entry.
