    Field markers¶

    Argument ¶

    Declare a tunable, range-checked model field.

    Argument is a subscript-only marker that builds a typing.Annotated type understood by @cm.declare / @cm.template. It is never instantiated — only subscripted on a class annotation. Supported forms::

    Argument[type]                  # required, no range/default
Argument[type, default]         # with a default value
Argument[type, (min, max)]      # range-checked, required
Argument[type, (min, max), default]

    The subscript accepts target_type (the field's type), optionally a (min_val, max_val) range, and optionally a default_val. An unsupported form raises TypeError.

    Constant ¶

    Declare a fixed, read-only field for templates and operator mixins.

    Constant is a subscript-only marker that builds a typing.Annotated type understood by @cm.template and @cm.module. The declared value is installed as a class-level descriptor, so it is visible as self.name/Cls.name but is never a constructor parameter::

    Constant[type, value]    # a fixed value checked once at declaration

    Constants work the same way on a @cm.template model and on a @cm.module mixin, where every implementing model inherits them.

    Variable ¶

    Declare a free internal-state field (no range check, no default).

    Variable is a subscript-only marker for model state that is not a tunable parameter::

    w: cm.Variable[np.ndarray]

    It wraps target_type (the field's declared type) in typing.Annotated metadata marking it as delayed-init state.

    apply ¶

    apply(x: NDArrayType, idx: RowSelection | None = None) -> None

    Vectorizes the target function to evaluate and update the solutions matrix.

    The internal buffer stores "fitness" in column 0 and "solutions" or "x" from column 1 onwards. Supports updating a single row, a slice, a list/array of indices, a boolean mask, or the entire active matrix if idx is None.

    Targets wrapped with cmenpy.target.vectorized_target score the whole block with a single call; the others fall back to a row-by-row evaluation. Either way the objective is charged exactly one evaluation per row scored: an individually selected row is dispatched as a one-row block, never as ndim separate entries, and a selection that picks no rows scores nothing at all.

    Parameters:

    Name Type Description Default
    x NDArrayType

    An array containing the new solution data to be inserted into the buffer.

    		 required
    idx RowSelection | None

    The row index, slice, or index mask to update. If None, defaults to the internal mask.

    		 None

    TargetFunction ¶

    TargetFunction(target: Target, bounds: Bounds, max_nfe: int | None = None)

    Wraps an objective, counting NFE and enforcing an optional budget.

    The wrapper scores solutions one individual at a time (evaluate) or a whole block at once (evaluate_matrix), increments the function-evaluation counter on every individual scored, and raises MaxNumberOfCalls once max_nfe is spent. A single individual always costs exactly one evaluation, whatever the shape of the objective underneath: a row written to a vectorized target is dispatched as a one-row block.

    evaluate_matrix(x: NDArrayType) -> NDArrayType

    Score a whole (pop, ndim) block and return a (pop,) vector.

    VectorizedTarget ¶

    VectorizedTarget(target: Target)

    A target that maps a whole (pop, ndim) matrix to a (pop,) vector.

    Marking a target as vectorized lets KernelBuffer.apply score a whole population with a single call instead of np.apply_along_axis, which spends one Python call per individual.

    Wrap target so it is dispatched as a whole-block evaluator.
