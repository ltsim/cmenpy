    Runtime¶

    The per-run machinery: the context handed to models, the epoch iterator, the history tracker and the seeded generator.

    Context ¶

    Context(f: Target, bounds: Bounds, buffer: KernelBuffer, generator: DefaultGenerator, sense: SenseType, epoch: int = 0, epochs: int = 0)

    Read-only view of the run handed to initialize/evolve.

    A fresh Context is built for every epoch. It exposes the search space, the population buffer, the random generator, the optimization sense, and the current/total epoch counters.

    Attributes:

    Name Type Description
    target TargetFunction

    The wrapped objective (counts NFE, enforces any budget).
    bounds Bounds

    The search space (low, up, ndim).
    buff KernelBuffer

    The buffer backing the population.
    rng Generator

    Seeded random generator.
    sense SenseType

    "min" or "max".
    epoch int

    Current epoch index.
    epochs int

    Total number of epochs.

    MainContextManager ¶

    MainContextManager(f: Target, bounds: Bounds, epochs: int, size: KernelSize, seed: int | None = None, debug: bool = False, sense: SenseType = 'min')

    Owns every per-run resource and builds the per-epoch Context.

    This is the internal orchestrator created by solve. It wires the objective, bounds, buffer, generator, tracker and epoch iterator together and hands out Context views.

    Parameters:

    Name Type Description Default
    f Target

    The objective callable.

    		 required
    bounds Bounds

    The search space.

    		 required
    epochs int

    Total number of epochs.

    		 required
    size KernelSize

    Population size (current, min, max).

    		 required
    seed int

    Random seed forwarded to the generator.

    		 None
    debug bool

    Record per-epoch history. Default False.

    		 False
    sense SenseType

    "min" (default) or "max".

    		 'min'

    Attributes:

    Name Type Description
    sense SenseType

    The optimization sense.
    epoch_it EpochIteration

    The epoch iterator driving the run.
    buffer KernelBuffer

    The population buffer.
    target TargetFunction

    The wrapped objective.
    bounds Bounds

    The search space.
    default_generator DefaultGenerator

    The seeded random generator.
    tracker Tracker

    The per-epoch history recorder.

    EpochIteration ¶

    EpochIteration(epochs: int, tracker: Tracker, target: TargetFunction, debug: bool = False)

    Epoch counter you iterate over; tracks per-epoch CPU time and NFE.

    An EpochIteration is the epoch argument passed to a @cm.declare function (and the object behind ctx.epoch / ctx.epochs). Iterating it yields 0 .. epochs - 1 and, when debug is enabled, records a EpochHistory snapshot after each epoch.

    Parameters:

    Name Type Description Default
    epochs int

    Total number of epochs; must be positive.

    		 required
    tracker Tracker

    Recorder populated each epoch when debug is true.

    		 required
    target TargetFunction

    Objective wrapper used to read the function-evaluation count (NFE).

    		 required
    debug bool

    Record a history snapshot per epoch. Default False.

    		 False

    Attributes:

    Name Type Description
    current int

    Index of the epoch most recently yielded.
    max int

    Total number of epochs.
    cpu_time float

    Wall CPU time spent in the most recent epoch body.

    Tracker ¶

    Tracker(buff: KernelBuffer)

    Records per-epoch snapshots of the population buffer.

    Parameters:

    Name Type Description Default
    buff KernelBuffer

    The buffer whose state is snapshotted on every track.

    		 required

    Attributes:

    Name Type Description
    history list[EpochHistory]

    Immutable copies of the tracked epochs, oldest first.

    EpochHistory dataclass ¶

    EpochHistory(epoch: int, best_idx: int, worst_idx: int, all: NDArrayType, timeit: int | float, nfe: int)

    Immutable snapshot of one epoch (only recorded when debug=True).

    Attributes:

    Name Type Description
    epoch int

    Epoch index.
    best_idx int

    Row index of the best individual at the end of the epoch.
    worst_idx int

    Row index of the worst individual at the end of the epoch.
    all NDArrayType

    Copy of the full population buffer (fitness in column 0).
    timeit int or float

    CPU time spent in the epoch.
    nfe int

    Function evaluations spent up to the end of the epoch.

    DefaultGenerator ¶

    DefaultGenerator(seed: int | None = None)

    Seeded random generator handed to models as ctx.rng.

    Parameters:

    Name Type Description Default
    seed int

    Seed for the underlying numpy.random.Generator. None seeds from OS entropy (non-deterministic).

    		 None

    Attributes:

    Name Type Description
    seed int or None

    The seed this generator was constructed with.
    rng Generator

    The live random generator used for sampling.
