    Models¶

    The declaration decorators, field markers, optimizer classes, protocols and support types that make up the model layer.

    declare ¶

    declare(*args: Any, **kwargs: Any) -> typing.Callable[[AlgorithmFunction], FunctionOptimizerModel]

    Turn a function into a model (the function-style API).

    The decorated function receives (args, epoch, ctx) and runs the whole optimization inside its body. Parameters are declared with cm.Argument and bound by calling the returned model.

    Parameters:

    Name Type Description Default
    **kwargs Any

    name=cm.Argument[...] field declarations.

    		 {}

    Returns:

    Type Description
    callable

    A decorator wrapping the function in a FunctionOptimizerModel.

    Examples:

    ::

    @cm.declare(x=cm.Argument[int, (0, 3), 2])
def my_algorithm(args, epoch, ctx): ...

model = my_algorithm(x=1)

    template ¶

    template(model: type[ModelProtocol]) -> TemplateOptimizerModel

    Turn a class into a model (the class-style API).

    The class must define initialize(self, ctx) and evolve(self, e, ctx); fields are declared with cm.Argument / cm.Variable. Kernels declared on the class receive the model's compile options at instantiation.

    Parameters:

    Name Type Description Default
    model type

    The class to wrap.

    		 required

    Returns:

    Type Description
    TemplateOptimizerModel

    A model wrapping the class.

    Raises:

    Type Description
    TypeError

    If model is not a class.

    Examples:

    ::

    @cm.template
class MyAlgorithm:
    a: cm.Argument[int, (1, 100)]

    def initialize(self, ctx) -> None: ...
    def evolve(self, e, ctx) -> None: ...

    Argument ¶

    Declare a tunable, range-checked model field.

    Argument is a subscript-only marker that builds a typing.Annotated type understood by @cm.declare / @cm.template. It is never instantiated — only subscripted on a class annotation. Supported forms::

    Argument[type]                  # required, no range/default
Argument[type, default]         # with a default value
Argument[type, (min, max)]      # range-checked, required
Argument[type, (min, max), default]

    The subscript accepts target_type (the field's type), optionally a (min_val, max_val) range, and optionally a default_val. An unsupported form raises TypeError.

    Variable ¶

    Declare a free internal-state field (no range check, no default).

    Variable is a subscript-only marker for model state that is not a tunable parameter::

    w: cm.Variable[np.ndarray]

    It wraps target_type (the field's declared type) in typing.Annotated metadata marking it as delayed-init state.

    prepare ¶

    prepare() -> dict[str, list[str]]

    Return the numba kernels declared on the wrapped class.

    Kernels compile on first use; this hook forces compilation with the model's compile options and reports their signatures.

    ModelProtocol ¶

    Bases: Protocol

    Protocol a @cm.template class must satisfy.

    The class must implement initialize (seed the population once) and evolve (advance one epoch).
